# Champion Arena

A gamified online examination and quiz platform.

## User Categories
- Student
- Admin

## Technology Stack

### Frontend
- React.js
- Tailwind CSS
- Motion for React

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

## Main Features
- Online quizzes and examinations
- Single-correct MCQ questions
- Reusable Question Bank
- Examination management
- Student performance tracking
- Leaderboard and achievements
- Gamified examination experience

## Project Structure
- frontend: React application
- backend: Express.js application
- database: PostgreSQL schema
- docs: Project documentation
